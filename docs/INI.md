# SplitSecondPad.ini reference

Every key of `SplitSecondPad.ini`. `glimpse_config.exe` sets all of them except the development keys in `[Debug]`; this is the reference for editing the file by hand.

The file is split into sections. INIs from older versions with everything under `[Game]` are still read.

**[Controller]**

| Key | Default | Meaning |
|---|---|---|
| `VirtualPads` | 4 | XInput slots exposed as pads (0–4). Lower this to make room for a wheel within the game's four-joystick limit. At 0 (or without an XInput DLL) the per-frame extras run from the game's input update instead of the pad poll. The game then reads the pad through DirectInput itself and acts on every button, and the fix cannot take a button away from it (the camera change on Y does not move to D-pad down). So the fix leaves the pad to the game: the boost, the handbrake, the power bar fill and the photo mode work with their keys only (`BoostKey`, `HandbrakeKey`, `PowerBarFillKey`, `PhotoModeKey` and the photo mode's keys), not with `BoostButton`, `HandbrakeButton`, LS+RS or Back, which would also do the game's own action. |
| `HideXInputFromDirectInput` | 1 | Don't offer the real XInput devices through DirectInput as well. |
| `SeparateTriggers` | 1 | 0 = stock shared Z axis. |
| `StickDeadzone` | 0.15 | Radial stick deadzone (0–1). |
| `TriggerDeadzone` | 0.05 | Trigger deadzone (0–1). |
| `RumbleStrength` | 1.0 | 0 = off. |
| `ButtonGlyphs` | xbox | `xbox`, `playstation` or `keyboard` (never switch). |
| `MenuRepeat` | 1 | On every build whose race cameras the fix hooks (the Steam version and its Russian depot). A held D-pad keeps scrolling in the menus (car select included): the press is one step, then after `MenuRepeatDelay` ms a step every `MenuRepeatRate` ms plus a 40 ms release. Each repeat is a short release (40 ms, and at least two reads of the pad) and press of the D-pad, so every screen counts exactly one step, as for a tap. For the XInput pads the fix presents (`VirtualPads`), not for DirectInput devices passed through. Not during a race; needs the race camera hooks (a known build). A direction pressed within 0.5 s of opening the pause menu still counts as held in the race: it repeats only after pressing it again. 0 = as the game (one step per press). |
| `MenuRepeatDelay` | 450 | Milliseconds the D-pad is held before the first repeat (100–2000). |
| `MenuRepeatRate` | 160 | Milliseconds between two repeated steps (80–1000), plus the 40 ms release: a step every `MenuRepeatRate` + 40 ms. Higher is slower and more precise. |

**[Graphics]**

| Key | Default | Meaning |
|---|---|---|
| `FrameRate` | 60 | 30 = stock. |
| `QualityCap` | 3 | The highest graphics quality level the game may use: 3 = no limit, 2 = High, 1 = Medium, 0 = Low. The game sets its level only through one function, which clamps it to the range of the level's tweakable; the fix lowers that range's maximum (data, before the game makes its device and every frame). The level chosen in the game's menu is kept and saved as it is and applies again once the limit allows it. |
| `TextureDetail` | 0 | 1–3 skip that many of the top mip levels of every mipmapped texture that is not a render target (half, a quarter, an eighth of the size), through the sampler state `MAXMIPLEVEL`. Textures without mip levels (the text, most of the HUD) stay as they are; menu and HUD pictures with mip levels get blurrier too. Changes only what is drawn, not what is loaded. 0 = stock. |
| `GlassFix` | 1 | Car glass as on the Xbox 360. Works on every build of the game: it uses only Direct3D and the shaders' code, no game addresses. The game's G-buffer keeps the specular intensity in the alpha of its first target and the specular power in the alpha of its third. The Xbox blends each target on its own and writes intensity 0 for the car windows; Direct3D 9 has one blend state for all targets, and the PC port's race pass writes the glass's opacity (about 0.87) as intensity while the power stays that of the surface behind. Where that power is 0 (the window frames of the converted DLC cars) the sun pass paints the glass flat white. The fix tags the glass pixel shaders (VehicleGlassAndDamage, VehicleGlass01) when they are made and changes only their draws with the race pass's exact blend state: alpha source factor ZERO (intensity 0) and no alpha write to the second target (it keeps the car's motion id). The states are put back after each draw; other draws cost one test. The glass of the base cars changes slightly too: no sun highlight on it, as on the Xbox; its reflections stay. Not done on a pure device (the game does not make one). 0 = stock. |
| `TextureLoadFix` | 1 | Skip CPU mipmap synthesis when loading 2D DDS textures that ship without mip levels. The game loads every texture through `D3DXCreateTextureFromFileInMemory`, which requests a full mip chain and decompresses, filters and recompresses single-level DXT textures on the CPU, stalling menu, HUD and post-race transitions. With `TextureLoadFix=1`, single-level 2D DDS textures — menu, HUD and post-race UI sprite sheets, as well as the level archives' single-level sky panoramas, `hdr_flare` lens flare sprites, `1024x32` colour-grading LUTs, bokeh sprites and a few single-level prop textures — are created with one mip level as authored (matching the Xbox 360 release), while pre-mipped streamed 3D world textures pass through unchanged. Compared in game at 720p with the fix on and off, skies, sun and distant light lens flares, and colour grading (`default`, `pause_menu`, `race_finished`) show no visible difference at `TextureDetail=0`. When `TextureDetail` is lowered (`1`–`3`), keeping those textures at one level also keeps single-level UI and skies sharp and prevents `TextureDetail` from downsampling the colour-grading LUTs into banded colours. 0 = stock. |
| `Anisotropy` | 16 | Anisotropic filtering 2–16, 0 = stock (linear). |
| `SMAA` | 1 | Anti-aliasing: SMAA 1x (the reference implementation by Jimenez et al.) on the 3D picture, right before the game draws its HUD with Scaleform, so text and HUD stay sharp. A frame without any HUD (photo mode) is smoothed at Present. About 0.1 ms per frame at 4K on an RTX 5090; at Very High, which renders at twice the resolution, about four times that. With `HDR=1` the light above paper white is not smoothed. 0 = stock (no edge smoothing; only Very High supersamples). |
| `MotionBlurStrength` | 1.0 | Motion blur multiplier on top of the 60 fps compensation. 0 = off. |
| `Vignette` | 0 | 1 = keep the cameras' darkened screen edges. |
| `Gradient` | 1 | 0 = no translucent blue band at the top of the screen. |
| `Bloom` | 1 | 0 = no bloom (glow around bright areas); the frame is still tone mapped. |
| `BloomStrength`, `BloomTone`, `BloomCurve`, `Exposure` | 1.0 | Multipliers on the cameras' bloom values (0–10): glow on bright areas, a softer second bright pass value, the add curve, the brightness of the whole picture. Read again every 2 s, so they can be tuned while the game runs. |
| `LensFlare` | 1 | 0 = no sun, light or screen space lens flares. |
| `ParticleFlare` | 1 | 0 = no flares from sparks, explosions and lights. |
| `FixPowerplayIconSize` | 1 | Powerplay icons and route change markers at console size at every resolution. 0 = stock. |
| `HudResolution` | 0 | Chase-camera HUD texture size. It holds text and the power bar in single-player and only the power bar in split screen. `-1` keeps original rendering. `1` keeps the original texture size and corrects the split-screen text colors (single-player text already used the correct path). `2` doubles the texture dimensions and `4` quadruples them. `0` (Auto) uses 2× up to 1080p effective 16:9 height and 4× above that or in split screen. On wider screens Auto uses the actual height with `UltrawideFix=1` or `2`. Steam build 385319 only (not the Russian depot). |
| `HDR` | 0 | 1 = HDR10 output for an HDR display (HDR switched on in the Windows display settings); the game runs in a borderless window. |
| `HDRPeakBrightness` | 1000 | The display's peak brightness in nits (400–10000), as the Windows HDR Calibration app finds it. The highlights of the game's HDR image go up to this. |
| `HDRPaperWhite` | 200 | Brightness of the game's white in nits (80–500). |

**[World]**

| Key | Default | Meaning |
|---|---|---|
| `StreamPoolMB` | 512 | Streaming pool in MB, 0 = stock (57). Only used when the exe has the LAA flag. |
| `LodDistanceScale` | 2.0 | Multiplier for LOD, streaming, particle, debris and powerplay distances (0.5–8). |
| `ShadowDistance` | 2.0 | Multiplier for the sun shadow range at the High and Very High quality levels in single player (1–3). The game: shadows reach 300 m and fade out over the last 100 m (`Lighting/CSM_Max`). Shadows close to the car get a little softer the higher it is. |
| `ShadowResolution` | 2 | Size of the sun shadow map: 1 = stock (one 1024x3072 depth texture, three cascades of 1024x1024), 2 = 2048x6144, 4 = 4096x12288 (experimental). The game never asks the map for its size and finds and filters a cascade in texture coordinates, so the fix creates both of its targets that many times as wide and high and scales the viewports, scissor and clear rects the game sets for them; the soft edge keeps its width and is sampled finer. Single player only; split screen keeps the game's two 1024x1024 maps. About 70 MB more graphics memory at 2, about 360 MB at 4. Where the device's largest texture is smaller the factor is lowered, and if a large target cannot be made the game's size is used; other values count as 2. |
| `Shadows` | 1 | 0 = nothing casts a shadow: the game's own switch `Lighting/Debug/Cast shadows - Disable all shadows`, which every pass that draws into the shadow maps checks. 1 = stock. |
| `PopInFix` | 1 | Ignore the sectors' precomputed visibility lists. 0 = stock. |
| `CarDetail` | 1 | Opponent car detail. The PC release loads the PS3's car LOD settings (`PlayerLOD_ps3.params`: at most 3 opponents in medium detail, coarse from 100 m on). 1 = the Xbox 360's (`PlayerLOD_xenon.params`: medium detail for all, coarse from 200 m on), 2 = high (also full detail for all opponents up to 40 m), 0 = as the PC release. |

**[Camera]**

| Key | Default | Meaning |
|---|---|---|
| `FOV` | 1.0 | Field of view of the race cameras as a factor of the game's own (0.3–2.5). |
| `UltrawideFix` | 1 | Screens wider than 16:9: 1 = the race cameras keep the picture height of 16:9, 2 = experimental full ultrawide (all cameras, menus and HUD at 16:9 in the centre), 0 = stock. |
| `UltrawideBlackBackdrop` | 0 | Car unlock, decal unlock and season reward screens in `UltrawideFix=2`: 0 = as the game (stock black bars with dimmed 3D track strips above and below the banner), 1 = solid black (full height: extends the top and bottom black bars to meet the banner, keeping text, icons and reveal art at their original proportions). |
| `ZoomKeys` | 0 | 1 = zoom the race camera while `ZoomInKey` / `ZoomOutKey` is held, `ZoomResetKey` back to `FOV`. |
| `ZoomInKey`, `ZoomOutKey`, `ZoomResetKey` | 0x31, 0x32, 0x33 | Virtual key codes (1, 2, 3 on the top row). |
| `PhotoMode` | 0 | 1 = photo mode with `PhotoModeKey` or the pad's Back button during a race. With `VirtualPads=0` keys only (see `VirtualPads`). |
| `PhotoModeKey` | 0x46 | Virtual key code (F). Keys the game uses itself (Esc, P, Enter, arrows) do not work, nor do the photo mode's own controls (W A S D, I J K L, Q E, U O, Shift, Ctrl, the zoom keys). |
| `CameraShake` | 1.0 | How much the race cameras (chase and bumper) shake on bumps and hits, against motion sickness: below 1.0 their rotation is smoothed (a low pass up to 0.12 s at 0.0), so quick shaking is filtered and turns follow a little later. |
| `ExplosionShakeOff` | 0 | 1 = no camera shake from explosions, collapsing buildings and power plays nearby (the game's own switch for it). |
| `HudKey` | 0 | Virtual key code that switches the HUD off and on during a race (0x48 = H). 0 = no key. |

**[Gameplay]**

| Key | Default | Meaning |
|---|---|---|
| `LapSelect` | 0 | 1 = on Quick Play Race's track select, the game's difficulty action (Tab / pad Y by default) picks from 1–10 laps and saves the choice as `Laps`. The button shows the track's default. The mode select, locked tracks, other modes, Season, split screen, LAN and online keep their stock input and laps. A changed-lap race keeps no personal best. Its finish card says "NO RECORD: LAPS CHANGED" where it would show "NEW PERSONAL BEST". A choice equal to the track's own count keeps stock laps and records. Steam build only (not the Russian depot). Requires `SteamLAN=0` and `PatchMask` bit `0x1000000`. 0 = stock. |
| `Laps` | 0 | The lap count picked with `LapSelect=1` (1–16; the track select picks 1–10, a higher value set here is used until the next pick). Written by the game. 0 = as the game. |
| `UnlockAll` | 0 | 1 = all tracks, events, episodes, game modes and vehicles selectable (the game's own switches; the profile is not changed). |
| `RaceEndTiming` | 0 | 1 = show Continue when the single-player finish card can accept it. Offline Quick Play gets a shorter entrance; Season plays the full credits and unlocks; split screen and online stay stock. Steam build only (not the Russian depot), requires the stock finish-card movie. |
| `CutsceneSkip` | 1 | Skippable cutscenes: the season's "Coming up" and "Next time" movies, the end sequence, the demo movies and the boot movies. The first press of A, B, X, Y, Start, Enter or Space shows "Press again to skip" for 3 seconds; a second press within them skips the movie, which the game then ends as if it had played to the end. The boot movies end on the first press, without the prompt, as in the game. Menu backgrounds and the tutorial clips are left alone. 0 = stock. |
| `SkipIntro` | 0 | Boot movies at every start: 1 = skip the publisher logo, 2 = also the game intro. They end at once without decoding (the movie files stay untouched). 0 = stock. |
| `BonusContent` | 0 | 1 = the PC version's cheat code extras: Expressway track, Cobretti SlipStream, retailer branded cars, Euro livery pack. |
| `WreckTime` | 0 | **Highly experimental: can softlock the game, especially together with the photo mode.** Seconds from a wreck of your car to the respot (about 4 s in the game; 0 = as the game): the game's respot logic is left out until then, the crash camera keeps showing the wreck. The photo mode holds the respot of all cars while it is on. |
| `UnlockDecals` | 0 | Achievements and their decals: 1 = all, 2 = only the unobtainable ones (achievements 41–46 from ranked online races and the Pure decal; the "all achievements" decal follows once the rest is earned). Unlocked in the next single player race and saved with the profile, so they stay when set back to 0; the Pure decal shows while this is set. The `.sav` files are copied to `glimpse_backup` before the first unlock. |
| `SaveBackups` | 0 | Backups of your saves at every game start: 1-5 = the save folder (`Documents\Disney Interactive Studios\Split Second`: the profiles `*.sav` and `config_ss.cfg`, no subfolders) is copied to `%LOCALAPPDATA%\glimpse_fix\save_backups\<nnnnnn_yyyymmdd_hhmmss>` (a running number, then the date and time of the start), and only that many copies are kept (the oldest is removed first). A start with saves that equal the newest copy byte for byte makes no new copy, so starting the game repeatedly does not push an older, different state out. The copy is made from outside the game on a thread of its own at the start; a file that changes while it is copied is copied again. The saves cannot be checked for damage (the game reads and writes them inside SecuROM's VM), so a damaged profile is copied like any other; the older copies stay. To go back: quit the game and copy a backup's files into the save folder (with Steam Cloud on, Steam may bring the newer files back: turn Steam Cloud off for Split/Second first). Works on every build. 0 = off. |
| `Boost` | 0 | 1 = X held gives player 1 extra speed along the car's heading; in split screen both players, each with their own pad (Steam build). |
| `BoostKey` | 0xA0 | Keyboard key for the boost, a virtual key code (0xA0 = left Shift). 0 = pad only. |
| `BoostButton` | X | Pad button for the boost: `X`, `Y`, `LS`, `RS` (stick clicks) or `None`. |
| `BoostAcceleration` | 15 | Boost in m/s² (1–100). |
| `BoostMaxSpeed` | 90 | No boost above this speed, m/s (10–200; 90 = 324 km/h). |
| `BoostMotionBlur` | 3.0 | Motion blur multiplier at full boost (1–5). |
| `PowerBarFill` | 0 | 1 = LS+RS (both sticks pressed) fills player 1's power play bar; in split screen each player's own. |
| `PowerBarFillKey` | 0xA2 | Keyboard key that works like LS+RS (0xA2 = left Ctrl). 0 = pad only. |
| `Handbrake` | 0 | 1 = handbrake for player 1 (in split screen for both players) while `HandbrakeButton` or `HandbrakeKey` is held (in a network race the host's setting applies to everybody). |
| `HandbrakeButton` | Y | Pad button: `X`, `Y`, `LS`, `RS` or `None`. When the boost or the handbrake uses Y, the game's camera change moves to D-pad down during a race. |
| `HandbrakeKey` | 0x20 | Keyboard key, a virtual key code (0x20 = Space, which neither of the game's keyboard layouts uses; X is "look back" in keyboard 0, the layout of a keyboard player in split screen). 0 = none. |
| `HandbrakeMode` | 1 | 1 = drift: the game's own slide physics (as when a power play blast throws a car sideways) with the pull and turn below. 2 = brake: the brake pedal fully pressed above 30 km/h, through the player's pad (its left trigger); a player without a pad (on the keyboard in split screen, or no pad at all) gets the drift (1) with the key. |
| `HandbrakeStrength` | 15 | Drift type: how hard the handbrake slows the car, m/s² (0–40). |
| `HandbrakeDrift` | 2.5 | Drift type: how fast the car turns into the slide at full steering, rad/s (0–5; 2.5 ≈ 140° a second). |
| `AIBoost` | 0 | Experimental: 1 = AI cars boost in bursts while behind player 1 or not far ahead. |
| `AIBoostLevel` | 2 | 1 easy (0.8× your boost, 3 s tank, up to 30 m ahead), 2 normal (1×, 5 s, about once a second, 60 m), 3 hard (1.3×, 8 s, almost constantly, 150 m). |
| `AIBoostUnlimited` | 0 | 1 = the AI's boost tank never empties. |
| `AIBoostStraightOnly` | 1 | 1 = AI boosts only on straights at speed, 0 = anywhere while driving forward. |
| `AIBoostChaos` | 0 | 1 = chaos mode: level 3, endless tank, anywhere, also far ahead of you, the AI's power play bar is always full and the AI drives at its highest skill (no slowing down when ahead). Overrides the three keys above while set. |
